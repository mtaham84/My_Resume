  • BigReport — CRM و سیستم مدیریت پذیرش و مالی سیستم اختصاصی کسب‌وکار · Production

    A full-stack Django back-office platform built for a real educational institute and currently running in production at bigreport.ir. The system manages the complete student journey — from the first CRM contact, through consultation and admission, to enrollment and installment-based payment — through dedicated, role-based dashboards for CRM agents, consultants, admissions/finance staff, and management. Delivered iteratively across multiple phases, with a running changelog documenting every new capability.

    Role-Based Sales Pipeline Students flow through a defined pipeline — CRM contact, initial admission gate, consultation, final admission, enrollment, financial settlement, completion — with every transition automatically logged as a PipelineEvent for a full, permanent history.
    Consultant Scheduling & Weekly Calendar Consultants publish open time slots; admissions staff book sessions with transaction-safe double-booking prevention, view a weekly calendar, and log session outcomes that drive the next pipeline stage.
    Admissions & Financial Module Auto-generated enrollment numbers, a per-enrollment financial ledger, and unlimited installments with method, due date, and reference tracking. Paid installments are immutable, and a scheduled management command automatically flags overdue payments.
    Performance Analytics & KPI Dashboard A ranked consultant/agent leaderboard built on three core KPIs — call response rate, consultation agreement rate, and verified attendance rate — each with a formula tooltip, filterable by date range, and exportable to Excel with one click.
    Drag-and-Drop Kanban Pipeline A dedicated Kanban board lets staff move students between stages with native HTML5 drag-and-drop, while transitions that require extra data (rejection reasons, financial entries) are guarded and redirected to the correct form to protect data integrity.
    Smart Reminder Engine An idempotent, cron-driven management command automatically notifies CRM agents of due and overdue follow-ups, consultants of today's sessions, and admissions staff of installments due — each item reminded exactly once per day.
    Persian-First, Role-Aware UX Full Jalali (Persian) calendar support throughout, RTL layout, dark/light themes, a glassmorphism design system, global sitewide search, in-app notifications, and duplicate-student detection with confirmation on new registrations.
    Python Django PostgreSQL Role-Based Access Control Jalali Calendar HTML5 Drag & Drop Cron Automation RTL / Persian UI

    Built and shipped in production for a paying client, with real users across four roles, real financial data, and a live, evolving feature set — not a tutorial project.

  • Self-Adaptive Machine Learning Trading System Featured AI Project

    An end-to-end machine learning-driven algorithmic trading system designed to predict next-day stock price direction and translate probabilistic predictions into executable trading decisions. The project goes beyond a typical academic ML experiment by implementing a complete pipeline that includes feature engineering, time-series-aware training, periodic model retraining, backtesting, dynamic risk management, position management, future trend forecasting, and an interactive graphical interface.

    Machine Learning Model Random Forest classifier with 150 trees, maximum depth of 10, and balanced class weights, selected for robustness against overfitting in noisy financial data.
    Feature Engineering 20+ technical and statistical features including lagged returns, SMA, EMA, MACD, RSI, Bollinger Bands, stochastic indicators, volatility, volume ratios, momentum, and ROC.
    Adaptive Training Pipeline The model is periodically retrained every 3–5 trading days using historical data available up to each prediction point, allowing the system to adapt to changing market regimes.
    Backtesting & No Look-Ahead Bias Each prediction is trained only on information available before that trading day, preventing look-ahead bias and respecting the chronological nature of financial data.
    Risk Management Dynamic stop-loss and take-profit levels based on ATR, combined with a dedicated position management system for converting model predictions into disciplined trading actions.
    Future Trend Forecasting A recursive Random Forest regression system forecasts the next 50 trading days and visualizes confidence intervals together with support and resistance levels.
    Interactive Application A Tkinter-based GUI provides date-range selection, live trade tables, equity curves, and interactive Matplotlib visualizations with zoom and pan capabilities.
    Python pandas NumPy scikit-learn Random Forest Matplotlib Tkinter Algorithmic Trading

    The system was trained and evaluated using more than a decade of daily AAPL market data, with dedicated attention to preventing data leakage, reducing over-optimization, and handling the non-stationary nature of financial markets.
