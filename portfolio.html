    Autonomous Agentic Pipeline Dedicated background agents and crawlers continuously monitor public Telegram chats and X streams, feeding normalized conversational data into a secure multi-schema data pipeline.
    Need Engine & LLM Reasoning Employs deep LLM reasoning to evaluate buying intent, distinguish serious purchase inquiries from casual chatter, and score opportunity quality on a 0–100 scale.
    Vector Search with PostgreSQL + pgvector Generates high-dimensional semantic embeddings for buyer needs and seller inventory, running cosine similarity queries directly inside PostgreSQL for ultra-fast, contextual matching.
    Automated AI Sales Pitch Drafting AI agents compose persuasive, natural, and context-aware responses and sales proposals ready for sellers to review and dispatch with a single click.
    Real-Time AI Inference Cost Auditing Tracks token consumption for every message and translates it into real-time operational costs in Tomans, guaranteeing cost predictability and positive unit economics.
    Containerized Production Stack Fully containerized using Docker and Docker Compose, running PostgreSQL 16 with pgvector, isolated worker microservices, and Nginx reverse proxy with field-level encryption.
    Python Django PostgreSQL pgvector Agentic AI & LLMs Docker Docker Compose Async Workers Telegram API REST APIs

  • Self-Adaptive Machine Learning Trading System Featured AI Project

    An end-to-end machine learning-driven algorithmic trading system designed to predict next-day stock price direction and translate probabilistic predictions into executable trading decisions. The project goes beyond a typical academic ML experiment by implementing a complete pipeline that includes feature engineering, time-series-aware training, periodic model retraining, backtesting, dynamic risk management, position management, future trend forecasting, and an interactive graphical interface.

    Machine Learning Model Random Forest classifier with 150 trees, maximum depth of 10, and balanced class weights, selected for robustness against overfitting in noisy financial data.
    Feature Engineering 20+ technical and statistical features including lagged returns, SMA, EMA, MACD, RSI, Bollinger Bands, stochastic indicators, volatility, volume ratios, momentum, and ROC.
    Adaptive Training Pipeline The model is periodically retrained every 3–5 trading days using historical data available up to each prediction point, allowing the system to adapt to changing market regimes.
    Backtesting & No Look-Ahead Bias Each prediction is trained only on information available before that trading day, preventing look-ahead bias and respecting the chronological nature of financial data.
    Risk Management Dynamic stop-loss and take-profit levels based on ATR, combined with a dedicated position management system for converting model predictions into disciplined trading actions.
    Future Trend Forecasting A recursive Random Forest regression system forecasts the next 50 trading days and visualizes confidence intervals together with support and resistance levels.
    Interactive Application A Tkinter-based GUI provides date-range selection, live trade tables, equity curves, and interactive Matplotlib visualizations with zoom and pan capabilities.
    Python pandas NumPy scikit-learn Random Forest Matplotlib Tkinter Algorithmic Trading

    The system was trained and evaluated using more than a decade of daily AAPL market data, with dedicated attention to preventing data leakage, reducing over-optimization, and handling the non-stationary nature of financial markets.
